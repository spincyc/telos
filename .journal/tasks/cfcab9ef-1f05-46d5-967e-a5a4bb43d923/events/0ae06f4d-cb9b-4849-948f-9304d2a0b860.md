# WinPE disk parser made utility-independent

The phase diagnostic reported code 20 at the first disk-count gate and showed
that `findstr` is absent from the selected WinPE image. DiskPart completed, but
the failed optional parser caused a zero count. No partition command ran and
the qcow2 remained effectively empty.

The parser now uses only `cmd.exe` `for` and nested `if` built-ins to select
the en-US DiskPart row. It still requires exactly one online disk, disk zero,
and exactly 256 GB, before and immediately before mutation. The contract test
forbids reintroducing `findstr`. All thirteen Windows install contract tests
pass.
