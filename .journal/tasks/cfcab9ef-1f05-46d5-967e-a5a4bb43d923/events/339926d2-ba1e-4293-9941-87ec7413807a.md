# Make PXE a one-shot workstation boot

The long run progressed through unattended image application and performed
its first Setup reboot with about 16 GB allocated. Firmware then selected PXE
again, began downloading the private WinPE overlay, and would have reached the
destructive startup path a second time. The runner was stopped before the
second WinPE reached DiskPart. Cleanup removed all QEMU and fabric children.

The workstation command now uses `-boot order=c,once=n,menu=off`: network is
selected only for the initial installation boot, while resets and later boots
select the NVMe disk. Device `bootindex` values that kept PXE preferred have
been removed. Fifty-seven focused factory and Windows lifecycle tests pass.
The first-pass installed evidence disk will not be reused.
