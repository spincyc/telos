# Guarded private Windows bundle preparation implemented

The new Make/CLI surface is dry-run by default. `APPLY=1` creates a fresh
private run directory, 256 GiB sparse qcow2, copied OVMF variables, exact QEMU
command and authorization receipt, randomized synthetic credentials, private
WinPE inputs, and a level-3 ISO containing the verified selected release and
complete sealed Windows source.

Plaintext generated inputs and the expanded publication tree exist only inside
bounded temporary contexts. The completed bundle retains the publication ISO,
disk, firmware state, digest-only authorization and non-secret command. Any
preparation failure removes the incomplete bundle. Twenty-five focused tests
and the Make dry run pass.
