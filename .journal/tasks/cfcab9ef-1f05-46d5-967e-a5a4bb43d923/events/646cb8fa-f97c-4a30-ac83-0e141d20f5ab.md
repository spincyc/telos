# Private WinPE overlay and install source publication implemented

Official wimboot behavior permits injected `install.bat` and `winpeshl.ini`
files without modifying the sealed stock boot WIM. The renderer now builds a
complete six-file private set, including the layout, answer file and protected
install password, while its retained receipt contains only names and digests.

Selected-release publication optionally accepts exactly that private set and a
receipt-verified complete Windows source. It checksums both into the disposable
Controller ISO, chains only the private boot script, binds Samba to the
isolated Controller address, uses an authenticated install-only account, and
exports the source read-only. Readiness requires HTTP, TFTP and SMB. Immutable
release bytes remain unchanged. Twenty-one focused tests pass.
