# Bound private Windows launch lifecycle implemented

The launcher fail-closes on a private non-symlink bundle, recomputes the
authorized command and standalone-disk integrity records, revalidates the sole
writable disk, attaches the private publication only to the disposable
Controller, and launches the Windows workstation with its persistent
fixed-serial NVMe disk and loopback socket NIC. Kernel-visible QEMU arguments
are re-audited after launch, including the explicitly authorized Windows
e1000e model.

Execution evidence is private, redacted, size-bounded, and records only a
failure type, never exception text that could contain private input. A signal
guard and bounded teardown cover every child and the disposable Controller
overlay. Any early child exit fails the run, and the isolated switch lifetime
exceeds the requested observation window. Thirty-six focused tests, bytecode
compilation, and a dry run against the prepared real bundle pass. No guest has
yet been booted by this checkpoint.
