# Persistent Windows install VM boundary implemented

The installation command now uses a persistent standalone qcow2 exposed as
fixed-serial NVMe, 8 GiB RAM, copied writable OVMF variables, PXE-first
`e1000e`, private read-only publication media, and a local QMP socket. It has
no Windows ISO, snapshot mode, user networking, TAP, bridge, guest agent or
host share.

The shared loopback QEMU audit now accepts an explicitly supplied NIC model;
all existing callers remain restricted to virtio-net. The Windows installer
supplies only `e1000e` for the stock WinPE driver contract. Twenty focused
installation and topology boundary tests pass.
