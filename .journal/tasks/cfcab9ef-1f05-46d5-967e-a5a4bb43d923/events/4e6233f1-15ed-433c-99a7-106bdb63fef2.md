# First boot exposed and fixed Samba ordering defect

The disposable Controller verified the complete release, private overlay, and
Windows source. Publication then stopped because `smbpasswd` attempted to load
the intentionally absent `/etc/samba/smb.conf`; the publisher had created that
file only afterward. The workstation was not launched, its disk was not
mutated, and bounded cleanup left no QEMU or fabric processes.

The publisher now writes the isolated-interface, authenticated, read-only
Samba configuration before adding the synthetic Samba account. A regression
test enforces this dependency order. Nineteen focused publication,
preparation, and lifecycle tests pass. The failed immutable bundle remains
evidence-only and must not be retried.
