# Send the unqualified standalone Samba user

Use `pxe-install` as the SMB client identity. In `net use`, `.\pxe-install`
qualifies the account against the WinPE client rather than proving the remote
standalone server's local namespace. Two live runs reached the numeric Samba
listener but received error 86 with that qualification, including after
normalizing the shared password input.

The unqualified name matches Samba's standalone passdb user and the share's
`valid users` rule directly. This retains authenticated, read-only access and
does not weaken the isolated publication boundary.
