# Mount SMB through an in-process WinPE credential helper

Use an injected VBScript helper and WinPE's sealed `cscript.exe` to read the
private password file in-process and call `WScript.Network.MapNetworkDrive`.
Four live `net use ... *` attempts returned error 86 despite proving the
numeric listener, account variants, normalized server input, and byte-identical
password lines. The evidence indicates that `net use` does not reliably read
its interactive password prompt from redirected WinPE input.

The helper contains no secret, receives no secret argument, prints no secret,
and overwrites its password variable after the API call. The source, account,
and helper remain synthetic, per-run, injected, and removed during teardown.
The existing authenticated read-only share boundary is unchanged.
