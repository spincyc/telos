# Bypass TPM and Secure Boot only for disposable QEMU acceptance

The disposable workstation command exposes neither a virtual TPM 2.0 device
nor Secure Boot firmware. For this synthetic acceptance lane only, WinPE sets
`BypassTPMCheck` and `BypassSecureBootCheck` immediately after the authorized
layout is applied and before Setup.

This does not change physical installation policy. A real workstation must
satisfy Windows 11 hardware requirements; the bypass is present only in
ephemeral private QEMU startup input and is removed during teardown. No CPU,
memory, disk-capacity, or disk-authorization check is bypassed.
