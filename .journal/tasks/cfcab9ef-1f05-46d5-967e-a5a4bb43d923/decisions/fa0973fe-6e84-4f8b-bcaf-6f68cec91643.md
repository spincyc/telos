# Bind disposable serial at the host boundary

The user authorized a two-part disposable-QEMU disk boundary because the
sealed stock WinPE image has no proven direct hardware-serial query:

1. the host binds the exact synthetic serial, disk file, capacity, layout, and
   sole writable-disk QEMU command into the authorization receipt; and
2. WinPE requires exactly one eligible disk with the authorized capacity,
   checking once before setup and again immediately before mutation.

This does not weaken physical launch. Hardware installation still requires the
real disk serial and explicit operator authorization.
