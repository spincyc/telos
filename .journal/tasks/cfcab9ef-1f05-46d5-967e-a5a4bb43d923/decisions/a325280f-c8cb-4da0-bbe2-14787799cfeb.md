# Permit private disposable Windows automation

The user authorized private per-run Windows startup and answer files for
disposable QEMU testing, using synthetic credentials, exact disk-serial
authorization, exclusion from Git and published releases, and mandatory
teardown. Physical launch will use user-supplied private values.

This resolves the task-level conflict between the active unattended acceptance
goal and ADR 0058. Repository ADR 0078 records the narrow supersession; the
physical installation contract remains interactive.
