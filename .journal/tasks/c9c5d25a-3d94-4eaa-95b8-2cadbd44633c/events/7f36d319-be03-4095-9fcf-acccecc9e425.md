# Arch kernel and initramfs handoff proven

Real release `.003` emitted early kernel output, ran `/init`, and entered
Archiso's PXE hooks. Network-root configuration then failed because initramfs
`ipconfig` selected `eth0` while udev renamed the same pinned virtio NIC.

The next immutable release binds the PXE MAC with `BOOTIF`, explicitly selects
`eth0`, and disables predictable renaming during initramfs. Evidence reporting
now distinguishes iPXE, kernel, Archiso-hook, and network-root phases. Gate
success still requires the root-image request and Arch userspace readiness.
