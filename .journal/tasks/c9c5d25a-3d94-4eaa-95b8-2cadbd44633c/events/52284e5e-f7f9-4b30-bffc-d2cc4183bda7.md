# Real Arch UEFI PXE handoff accepted

The exact `.004` initramfs proved that combining `BOOTIF` with an already
expanded device-form `ip` argument made Archiso append the interface twice.
Release `.005` keeps the pinned MAC and stable interface naming but supplies
literal `ip=dhcp`, allowing the hook to construct the supported form.

A real 180-second OVMF run on the loopback-only fabric accepted immutable
release `.005`: gateway-only DHCP, iPXE bootstrap, kernel and initramfs,
Archiso DHCP, `airootfs.sfs` HTTP retrieval and mount, and `archiso login:`
were observed. Success evidence is now retained privately as well as failure
evidence, and the Make surface can explicitly pass the selected release root.
The remaining acceptance item for this task is a real WinPE handoff.
