# Kernel handoff diagnostics isolated

Real release `.002` downloaded the selected bootstrap, kernel, and complete
initramfs, then transferred control without returning an iPXE failure. A
direct no-network Q35 diagnostic proved those exact kernel/initramfs bytes
enter the kernel and Archiso hooks with an explicit early serial console.

The next immutable release adds early UART output, makes serial the primary
console, and distinguishes pre-boot image readiness from a returned boot
failure. Acceptance still requires an actual kernel or userspace marker and
does not count the iPXE pre-boot marker as handoff.
