# Keep remediation separate from the requested audit

The user's request is to audit every hands-on project, prioritize Potato
Launcher, and document durable curriculum guidance. The draft acceptance
criterion saying to bring Potato Launcher into compliance expanded that
request from audit into implementation of a large multi-publication art
backlog.

Completion therefore requires a detailed potato-first remediation gate, not
all resulting drawings. `src/HANDS-ON-VISUAL-AUDIT.md` supplies stable gap IDs,
evidence boundaries, and completion checks so later curriculum work can
implement the findings without silently broadening this audit task.
