# Real mkarchiso output corrected the Controller contracts

A rootless disposable build exposed two fixture blind spots before any
publication: current Archiso emits EROFS plus a SHA-512 sidecar, and the
custom profile lacked the HTTP-PXE initramfs hooks. Controller intake now
accepts exactly one supported root image, verifies the upstream checksum, and
uses current HTTP boot arguments.

The profile now declares the minimal UEFI HTTP-PXE hook chain and its staging
audit requires those hooks, wired DHCP activation, and absence of MEMDISK,
NBD, and NFS transports. The invalid pre-fix output was not imported or
selected. Full validation passes with 31 root and 827 homelab tests.
