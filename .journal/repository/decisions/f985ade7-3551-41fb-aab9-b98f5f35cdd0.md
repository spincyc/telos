# Exclude Worktree Marshal and preserve factory dependency order

Worktree Marshal work is intentionally omitted. Repository verification and
durable-state reconciliation are prerequisites for factory execution. Factory
installation and acceptance tasks remain serialized where they mutate shared
generated state. Documentation follows implementation stabilization. External
integration is planning-only and performs no external mutation.
