\begin{telospanel}{Final proof}
Do not mark complete because every written step was attempted. Mark complete
only when the guide's observable pass condition is present, the safety chain
is intact, and another person could repeat the action from this record. If the
result is ambiguous, record a fail and choose one corrective action.
\end{telospanel}
