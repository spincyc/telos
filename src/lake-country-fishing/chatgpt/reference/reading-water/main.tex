\section{Three-pass method}
First pass maps depth, bottom and cover. Second pass holds presentation constant
through the best feature. Third pass changes one variable. A named “spot” is
only a hypothesis until current evidence supports it.
\begin{teloshazard}{Map discipline}
Historical lake contours are generalized and not for navigation. Watch traffic,
weather, depth and hazards directly. Never stare at electronics while underway.
\end{teloshazard}
