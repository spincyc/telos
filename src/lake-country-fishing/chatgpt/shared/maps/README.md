# Lake-map provenance

These are original black-and-white line drawings for the ChatGPT edition. They
do not import geometry, prose, labels or generated map output from the Claude
edition.

## Pine Lake

- Identity: WBIC 779200.
- Bathymetric basis: Wisconsin Conservation Department survey, 1955-06-06,
  distributed by Wisconsin DNR as a public document and marked not for
  navigation.
- DNR document:
  https://apps.dnr.wi.gov/swims/Documents/DownloadDocument?id=29815201
- Modern context check: Wisconsin statewide 2024 NAIP aerial orthophotography,
  USDA/FSA, 0.6 m. Consulted for gross shoreline, island, roads and access
  context; no pixels are reproduced.
- Drawing: manually generalized TikZ paths and independently selected
  structure-hypothesis markers.

## North Lake

- Identity: WBIC 850800.
- Bathymetric basis: Wisconsin Conservation Department survey compiled in
  1898 and revised 1941, distributed by Wisconsin DNR as a public document and
  marked not for navigation.
- DNR document:
  https://apps.dnr.wi.gov/swims/Documents/DownloadDocument?id=29815291
- Modern context check: same 2024 NAIP source. No pixels are reproduced.
- Drawing: manually generalized TikZ paths and independently selected
  structure-hypothesis markers.

## Imagery rights and limitation

NAIP is a federal USDA/FSA imagery program. The Wisconsin 2024 overview is:
https://www.arcgis.com/home/item.html?id=b7a9cc807a93412db729617af72a8c0a

WisconsinView describes the statewide archive as public-domain imagery. The
maps use it as visual research only, so the deliverables contain no raster
imagery or derivative photographic texture. Neither map is a survey, ownership
map, access grant or navigation chart.
