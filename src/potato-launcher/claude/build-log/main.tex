\telosmasthead[One sheet, one build --- the evidence that it is sound]

This is the difference between a launcher you hope is fine and one you know is
fine. Fill it in as you go, not afterwards from memory. Every blank on this page
exists because somebody, somewhere, guessed instead of checking.

\begin{telospanel}{How to use this log}
Read the governing build procedure and craft sheets before work. Then keep the
following record packet together and complete each table at the named hold
point. Do not reconstruct entries later. A blank, uncertainty, or failed check
is a hold; the adult in charge decides whether the affected part is remade or
retired.
\end{telospanel}

\begin{telospanel}{Record sequence}
\begin{enumerate}[leftmargin=1.6em,itemsep=0.25em]
\item Identify the governing drawing.
\item Name the adult with stop authority.
\item Copy every pressure-part rating before measuring; an absent or
nonmatching rating places that part on \textsc{hold}.
\item Record each cut and edge inspection before joining.
\item Record each joint while it is fresh; any blank or failed observation
places the affected assembly on \textsc{hold}.
\item Calculate the cure gate from the latest weld.
\item Close every fault by accept, remake, or retire.
\item Complete final visual proof only after cure.
\item Complete the session sheet before each later use.
\end{enumerate}
\end{telospanel}

\begin{teloshazard}{Records never overrule a defect}
Good paperwork cannot make a cracked, crazed, distorted, misaligned, unknown,
or incompletely cured pressure part acceptable. Stop, mark the fault, isolate
the part, and follow the remake record. Firing is never an inspection method.
\end{teloshazard}

\begin{gate}{Stop here if any line does not say pressure-rated}
Every pressure-bearing part must read \textbf{Schedule 40} with an
\textbf{NSF-PW} rating and a pressure figure. If a part says DWV, cellular core,
foam core, or carries no pressure rating at all, it does not go in this build.
Mark it \textsc{reject}, isolate it from accepted stock, and obtain a traceable
replacement before continuing.
\end{gate}

\begin{telospanel}{Permitted dispositions}
\textbf{Accept} only when the drawing and every stated criterion are met.
\textbf{Remake} means a new part or assembly, followed by every earlier check
that the replacement affects. \textbf{Retire} means mark it permanently, isolate
it, and make it unusable. There is no ``use carefully,'' ``probably fine,'' or
performance-based exception.
\end{telospanel}

\begin{gate}{Final release is not a firing test}
Do not use firing to prove that construction is sound. Release means only that
the documented build and inspection criteria have been met. It does not waive
the separate pre-firing inspection, site controls, or adult stop authority.
\end{gate}

\begin{telospanel}{Why a form, and not just care}
Memory is confident and wrong. ``I'm fairly sure'' is not evidence. A dated
entry removes the argument before it begins and lets another person verify the
same facts.
