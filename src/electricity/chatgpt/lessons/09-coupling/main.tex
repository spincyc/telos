\def\procedure{\small
\begin{enumerate}
  \item Tape both coils coaxial at \(d=0\) cm. Fix the battery, button, meter
  range, lead routing, and one operator. Mark coil faces and lead polarity.
  \item Make five brief, equally timed button presses. Record the largest
  absolute receiver voltage for each make pulse; use their median. Also record
  the break-pulse sign. Stop if a coil or cell warms.
  \item Repeat at \(d=1,2,4,8\) cm. Move only the receiver along the common
  axis. Do not stretch or reroute leads.
  \item Return to \(d=2\) cm. Repeat at \(\theta=0^\circ,30^\circ,60^\circ,
  90^\circ\), rotating about the receiver's center.
  \item Repeat the distance series with the removable iron core linking both
  coils. Remove it between trials; check that the zero-gap baseline returns.
\end{enumerate}

\def\explanation{\small
The transmitter's changing current makes changing magnetic flux. The receiver
responds only to the portion linking its turns:
\[
  V_{\mathrm{RX}}\approx -M\,\frac{\Delta I_{\mathrm{TX}}}{\Delta t},
  \qquad M=k\sqrt{L_{\mathrm{TX}}L_{\mathrm{RX}}}.
\]
Geometry and the core change the coupling factor \(k\); the button edge changes
\(\Delta I/\Delta t\). A steady held current has flux but little change, so the
receiver pulse falls toward zero. Releasing the button reverses the flux change
and therefore the pulse polarity. This is induction, not wireless creation of
energy.

\begin{teloscard}{Interrogate the evidence}
\footnotesize\begin{multicols}{2}
\begin{enumerate}[leftmargin=*,itemsep=.22em]
\item Which single trial is your baseline?
\item Did five pulses agree closely enough to compare?
\item What happened when \(d\) doubled?
\item Is the distance trend linear? What evidence says so?
\item Why must the coil centers stay on one axis?
\item At which angle did the response halve?
\item Was \(90^\circ\) exactly zero? Why might it not be?
\item Did the core multiply every distance by the same factor?
\item Which result supports shared flux rather than lead length?
\item Why is the held reading not the comparison value?
\item Why do make and break pulses have opposite signs?
\item Which variable changes \(M\)? Which changes \(\Delta I/\Delta t\)?
\item What observation would falsify your geometry claim?
\item Where is measurement resolution limiting the conclusion?
\end{enumerate}
\end{multicols}
\end{teloscard}}

\begin{gate}{Final proof}
Blind the receiver configuration behind a sheet. A partner chooses two of
these states: coaxial/near, coaxial/far, orthogonal, or common-core. From five
pulses per state, predict which geometry is which and justify the identification
from the distance, orientation, and core graphs. Then swap roles. The claim
passes only if both identifications are correct, the baseline returns within
the trial spread, and make/break polarity reverses. Record any failure as
evidence and isolate it before repeating.
\end{gate}}
