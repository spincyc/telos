\def\procedure{\begin{enumerate}\item Read Safety with the learner and assign roles.
\item Take Lessons 1--7 in order; they establish charge, field, measurement, induction, ratio, and stored energy.
\item Lessons 8--10 connect resonance, coupling, and historical discharge apparatus without crossing into learner high voltage.
\item Use demonstrations after their named prerequisite. Build the low-voltage coupled-coil instrument only after Lessons 1--9.\end{enumerate}}
\def\explanation{The course treats a model as useful only when it predicts an observation. Each lesson follows the same loop: predict, assemble deenergized, adult inspection, energize briefly, measure, disconnect, explain. The final machine is not the purpose; it is a test of whether the learner can follow energy and fields across several representations.}
\def\extension{Make a concept map after every lesson. Draw a solid arrow for a measured connection and a dotted arrow for a question. Revisit and revise rather than erase.}
