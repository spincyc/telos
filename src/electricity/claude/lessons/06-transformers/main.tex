\begin{enumerate}
\item Set the secondary meter to DC volts and its highest suitable range.
\item Tap the button and note the first deflection: this is \textbf{make}.
Observe the reading while held very briefly, then release for \textbf{break}.
\item Repeat three times. Record signs as well as magnitudes.
\item Reverse only the secondary leads and repeat. Predict before tapping.
\item With the battery removed, open the core joint slightly; reconnect and
repeat one cycle. Restore the closed core afterward.
\end{enumerate}

\begin{teloscard}{Worked forecast}
With \(N_p=40\), \(N_s=120\), and a measured primary transition of
\(\qty{2.2}{V}\), the ideal prediction is
\[
\lvert V_s\rvert=\qty{2.2}{V}\left(\frac{120}{40}\right)=\qty{6.6}{V}.
\]
If the secondary pulse supplies \(\qty{8}{mA}\), ideal power balance gives
\(I_p\approx I_s(N_s/N_p)=\qty{24}{mA}\). Voltage can rise only as available
current falls.
\end{teloscard}

\begin{telosfacts}[0.22]
\telosfact{Copper}{Long, fine wire has resistance. Load current produces heat
and terminal-voltage sag.}
\telosfact{Core}{Magnetization lags the field; induced currents circulate
within each lamination. Both consume input energy.}
\telosfact{Coupling}{Some primary flux does not link every secondary turn.
A loose joint or physical gap makes this worse.}
\telosfact{Measurement}{Hand switching is not a calibrated waveform. Compare
trends and polarity; do not claim precision from short-lived meter peaks.}
\end{telosfacts}
