\telosmasthead[The first lesson with an acceptance record]
\lessonhead{3}{two sessions}{learner work: isolated two-AA source only}

\begin{materials}
\item Digital multimeter with intact leads and fused current input
\item Switched holder and two AA cells
\item 100, 220, 470 \(\Omega\), 1 k\(\Omega\), and 10 k\(\Omega\) resistors
\item Solderless breadboard and insulated jumpers
\item Graph paper, pencil, and the meter manual
\end{materials}

\begin{predict}
At the same loaded source voltage, rank the five resistors by current. Predict
the current for each using \(I=V/R\), then mark which prediction is most
sensitive to meter resolution.
\end{predict}

\begin{teloshazard}{The dial, jacks, and leads form one instrument}
Current mode presents a low-resistance path. Never connect an ammeter across a
cell or battery holder. Rewire only with the switch open and the holder
disconnected. After every current reading, remove power and return the red lead
to the V/\(\Omega\) jack. Stop immediately for warmth, odor, damaged insulation,
an unstable display, or an unexpected reading.
\end{teloshazard}

\lessonsection{The questions the circuit must answer}
\begin{multicols}{2}
\begin{enumerate}
\item Does the isolated resistor agree with its marked value?
\item Does a voltmeter placed across it report the loaded voltage?
\item Does an ammeter inserted in the only path report the path current?
\item Does \(V_R/I\) agree with resistance mode?
\item Are two independently rebuilt runs repeatable?
\item Does the \(V_R\)-against-\(I\) graph have the expected slope?
\item Is any disagreement larger than the combined uncertainty?
\item Can a fault be localized without random rewiring?
\end{enumerate}
\end{multicols}

\lessonsection{Run the verification}
\begin{enumerate}
\item Execute State 0. Do not proceed until maximum predicted current and
meter range are compatible.
\item Execute State 1 for every resistor. Record function, range, resolution,
and reading.
\item Build State 3 for the 10 k\(\Omega\) resistor first. Record \(V_R\) and
loaded \(V_s\). Open and disconnect.
\item Rebuild as State 4. Record \(I\). Open, disconnect, park the red lead.
\item Remove the resistor and rebuild the entire circuit for run 2. Repetition
without rebuilding tests display stability; rebuilding also tests connection
repeatability.
\item Continue toward smaller resistance only while the predicted current
remains comfortably within the selected fused range.
\item Compute \(R_{VI}=V_R/I\), \(P=V_RI\), and percent difference from
resistance mode. Plot \(V_R\) vertically against \(I\) horizontally.
\end{enumerate}

\lessonsection{Worked result: arithmetic with units}
For \(V_R=2.86\ \mathrm{V}\) and \(I=12.9\ \mathrm{mA}
=0.0129\ \mathrm{A}\),
\[
R_{VI}=\frac{2.86\ \mathrm{V}}{0.0129\ \mathrm{A}}
=222\ \Omega,\qquad
P=(2.86\ \mathrm{V})(0.0129\ \mathrm{A})=0.0369\ \mathrm{W}.
\]
For a 220 \(\Omega\), 5\% part, the marked interval is
\(220(1\pm0.05)=209\) to \(231\ \Omega\). The result is consistent with the
marking, subject to meter uncertainty and run-to-run variation.

\lessonsection{Uncertainty: say what the meter can support}
Copy each relevant accuracy specification from the meter manual. For a
specification \(\pm(a\%\text{ reading}+b\text{ counts})\),
\[
u_x=\frac{a}{100}|x|+bq,
\]
where \(q\) is the displayed resolution. If \(V=2.86\ \mathrm{V}\), \(q_V=0.01\
\mathrm{V}\), and accuracy is \(\pm(0.5\%+2\text{ counts})\), then
\[
u_V=0.005(2.86)+2(0.01)=0.0343\ \mathrm{V}.
\]
For a conservative resistance bound,
\[
\frac{u_R}{R}\leq\frac{u_V}{|V|}+\frac{u_I}{|I|}.
\]
Add half the absolute difference between the two rebuilt runs if it is larger
than the resolution contribution. Report no decimal place finer than \(u_R\).

\lessonsection{Questions from the graph and the circuit}
\begin{multicols}{2}
\begin{enumerate}
\item Which axis choice makes slope equal resistance?
\item Why record loaded rather than only open-circuit source voltage?
\item Why is \(V_R/I\) a stronger check than current alone?
\item Should a best-fit line be forced through zero? What evidence decides?
\item What would curvature suggest about temperature or non-ohmic behavior?
\item Why might resistance mode and \(V_R/I\) differ?
\item For which part does lead resistance matter most?
\item For which current is meter resolution most important?
\item How can ammeter burden voltage change the circuit?
\item Why is a continuity tone not proof of a sound loaded connection?
\item When does ``OL'' mean open, and when only over-range?
\item Which anomalous result must stop the whole series?
\item Does interval overlap prove the law? What does it actually show?
\item What independent observation would strengthen your conclusion?
\end{enumerate}
\end{multicols}
