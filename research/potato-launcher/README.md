# Potato launcher shared research

Provider-neutral evidence for editions of the Telos potato-launcher project.
This directory is a claim library, not a finished narrative and not an
endorsement of any launcher design. Each edition selects claims explicitly and
remains responsible for the conclusions it draws.

## Contract

- `sources.md` records authoritative sources and access metadata.
- `claims.md` breaks evidence into atomic, reusable claims.
- An edition records the claims it uses in its own selection manifest.
- `Source says` means a close paraphrase. `Inference` means an edition author
  has combined evidence with a stated conservative judgment.
- A pressure marking on a plumbing component is not treated as manufacturer
  approval for combustion, pneumatic, or projectile-launcher service.
- Local law and site rules must be checked for the actual place of use.
